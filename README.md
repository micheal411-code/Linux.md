# Linux.md
Linux is a free, open-source operating system used to run computers, servers, smartphones, and other devices. It is similar to Microsoft Windows and macOS, but it gives users more control over the system.
Since you're interested in computer science and programming, learning Linux can help you with web development, Python, networking, and server administration.
1. What is Linux used for?
- Web development: Running websites and web applications.
- Programming: Writing and executing Python, Java, C, and other programs.
- Cybersecurity: Learning network security and system administration.
- Servers: Hosting websites, databases, and applications.
- Networking: Managing connections, permissions, and system services.
2. Basic Linux commands
Here are some essential commands to start learning.
Command	What it does
pwd	Shows your current directory
ls	Lists files and folders
cd	Changes directory
mkdir	Creates a directory
touch	Creates an empty file
cat	Displays file contents
cp	Copies files
mv	Moves or renames files
rm	Removes files
clear	Clears the terminal screen
whoami	Shows your current username
Example
pwd
mkdir myproject
cd myproject
touch hello.py
ls




This sequence shows your current location, creates a folder called myproject, enters it, creates a Python file, and lists the folder contents.

4. Your Linux learning roadmap
1. Week 1: Learn the terminal and basic commands.
2. Week 2: Understand files, folders, permissions, and users.
3. Week 3: Learn package installation, processes, and system management.
4. Week 4: Practice Python programming, Git, and running a Flask web application.
